    en: 'Cyber-Physical System (CPS) closely integrates communication, computing and control, enabling real-time interaction and dynamic optimization between the cyber layer and the physical layer. CPS has a wide range of applications in the fields of smart home, smart transportation, telemedicine, smart manufacturing and military, etc. However, with the occurrence of the Stuxnet attack, the security issue of cyber- physical systems has received great attention. Focusing on the security of cyber- physical systems, this course focuses on the concept of cyber-physical systems, introduces relevant attack cases, talks about how to analyze the security of cyber- physical systems from the perspective of automatic control, and designs security control strategies. On this basis, the students are led to conduct relevant experiments based on the laboratory''s autonomous intelligent unmanned system experimental platform (unmanned vehicles, drones, robotic arms, air-floating platforms, etc.). The experiments demonstrate the impact of network attacks on system security and verify the designed security control algorithms. The course belongs to an emerging cross-study area, and the main contents of the course include: overview of cyber-physical systems, introduction to cyber-physical system security, cyber-physical system security analysis, and secure sliding-mode control design under deception attack scenarios.'
