This course mainly teaches the single closed-loop speed control system of DC motor, the double closed-loop speed control system of DC motor, the digital control technology of DC motor control, asynchronous motor speed control system based on static model, and asynchronous motor speed control system based on dynamic model. Aiming the problem of electric drives control, this course explains how to apply automatic control theory to analyze and design motion control systems. Tracking the torque and flux control, the analysis and design methods of motion control systems are gradually explained from open-loop control to closed-loop control, and from DC motor drive to AC motor drive. Focus on cultivating students' ability to analyze and design complex engineering problems using basic theoretical knowledge, this course emphasizes improving the students’ innovation ability.
