    en: This course is mainly aimed at undergraduate students majoring in intelligent measurement and control engineering. This course condenses the core content of courses such as data structures, operating systems, databases, computer networks, and software engineering, and teaches the basic concepts, principles, and methods of computer software technology. The combination of this course with courses such as "Advanced Language Programming" and "Principles of Microcomputers and Microcontrollers" can enable students to comprehensively grasp the basic principles and methods of computer software and hardware, laying a foundation for the comprehensive application of their professional knowledge and computer knowledge. In the course, the focus is on teaching the basic concepts and operations of linear tables, stacks, queues, arrays, and trees, as well as algorithms for searching and sorting, in order to enable students to have a basic understanding of the organization, storage, and processing methods of data in computers. The operating system focuses on teaching the basic principles and methods of memory management, processor management, device management, and multithreading, enabling students to have a preliminary understanding of the resource management mechanism of the operating system. The database mainly introduces the standardized design of relational databases and SQL language, enabling students to initially master the methods of database design and operation. Computer networks mainly introduce network architecture and main network protocols, enabling students to understand the operating mechanism of computer networks. Software engineering focuses on teaching structured software development techniques, enabling students to initially master standardized software development methods tailored to specific requirements. This course introduces the methods of using the knowledge of this course to develop embedded software, instrument driver software, measurement and control system software, and other professional software, so that students have the ability to solve engineering application problems.
