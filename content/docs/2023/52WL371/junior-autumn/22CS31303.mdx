They must fully understand important impact of non-functional requirements on software quality, and master the basic software architecture design techniques. Furthermore, the students must be able to make reasonable selection and evaluation of software architecture for specific non-functional requirements. They must be able to use typical architecture design techniques to handle the issues caused by different non-functional requirement and its evolution.
