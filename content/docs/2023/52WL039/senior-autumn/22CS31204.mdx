    en: 'Internet infrastructure is a collection of systems that are essential for the operation of the Internet. Key Internet infrastructure mainly includes Domain Name System (DNS) and Inter-domain Routing System (Border Gateway Protocol, BGP). The Internet is the main carrier of cyberspace, and ensuring the security of Internet infrastructure is also the key to ensuring the security of cyberspace and maintaining network sovereignty. Comprehensive and in-depth mastery of the attack and defense methods and principles of Internet infrastructure is an important demand for cyberspace security talents. This course cultivates the practical ability of Internet infrastructure security, covering 4 parts: network topology measurement, inter-domain routing security, domain name system security, and secure network protocol design and implementation. For network topology measurement, practical experiments on network topology detection will be carried out, and IP-level topology maps will be drawn for designated network segments; for inter-domain routing security, practical experiments on BGP system attack and defense will be carried out, and prefix hijacking attacks and route leaks will be simulated based on the virtual shooting range platform. Risks, observe the attack process and analyze the impact of the attack, practice BGPSec, RPKI and other protection solutions, and evaluate the protection effect and cost; for domain name system security, we will conduct practical experiments on DNS system attack and defense, and simulate cache poisoning and reflection attacks based on the virtual shooting range platform , observe the attack process and analyze the impact of the attack, practice DNSSEC, DoH and other protection solutions, and evaluate the protection effect and cost; for the design and implementation of secure network protocols, a common network protocol will be selected to design a security protection in the form of group collaboration The solution is implemented and verified based on the ns3 simulation experiment platform. Submit code and reports, and demonstrate the system. By studying this course, students will have solid practical capabilities in Internet infrastructure security and have a deep understanding of relevant attack and defense principles.'
