    en: This course is a basic course in the field of automatic control and is optional for students majoring in electrical engineering. The purpose is to enable students to master the basic theories and methods of linear multivariable systems in modern control theory, laying a foundation for further study of subsequent courses and research on related disciplines. The content of this course mainly focuses on linear steady systems, using the state space method to establish the state model of the system, analyze the system and correct the system. Through the study of this course, students should understand the content, research methods and concerns of modern control theory; be proficient in the establishment of state variables and state space expressions; master the definition, controllability and observability of linear continuous steady systems; master Lyapunov's definition of stability, Lyapunov's second method, and the application of Lyapunov's method in linear/nonlinear systems; master the basic structure and characteristics of linear feedback control systems, solve pole configuration problems, system stabilization problem, system decoupling problem, design state observer and use state observer to realize state feedback system.
