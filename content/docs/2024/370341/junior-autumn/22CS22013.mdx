    en: 'A database system is a vital computer software system and serves as critical infrastructure for data management. This course teaches the fundamental concepts of database systems, database languages, core principles of database management systems, and essential methods of database design. It aims to develop students'' capabilities in data modeling, applying database technologies to analyze and solve data management problems, constructing relatively complex computer system software, transferring knowledge across different types of database systems, and cultivating systematic thinking and professional communication skills in computer system software development. The specific course objectives are as follows: Course Objective 1: Master the basic concepts of database systems, database languages, and fundamental principles of database management systems; be able to use a database management system to store, query, and update data; optimize data management through techniques such as indexing, views, and query rewriting; and develop the ability to analyze and solve data management problems using database technologies. Course Objective 2: Master the basic methods of database design; be able to analyze data management application requirements, design databases rationally, and evaluate them scientifically; develop data modeling capabilities oriented to application needs. Understand the basic architecture of a database management system kernel; be able to comprehend, design, and test kernel programs of a database management system; and acquire the ability to construct relatively complex computer system software. Course Objective 3: Understand the development trends of database technologies and develop the competency to transfer knowledge across different types of database systems. Recognize the complexities of database system design, be able to analyze the strengths and weaknesses of system design solutions, and cultivate systematic thinking and professional expression skills in computer system software development. The teaching content includes an overview of database systems (2 class hours), the relational data model (3 class hours), the standard relational database language SQL (3 class hours), storage management (4 class hours), indexes ( class hours), query processing (4 class hours), query optimization (4 class hours), transaction management (2 class hours), concurrency control (4 class hours), failure recovery (4 class hours), database design (4 class hours), new database technologies (2 class hours), lab on the implementation of buffer pool manager (2 class hours), lab on the implementation of record manager (2 class hours), lab on the implementation of data definition (2 class hours), and lab on the implementation of data manipulation (2 class hours). The teaching method adopts a student-centered approach, combining classroom lectures, MOOC, demonstration, and experiments.'
