    en: 'Internet infrastructure is a collection of systems that are essential for the operation of the Internet. The key Internet infrastructure mainly includes the Domain Name System (DNS) and the Border Gateway Protocol, (BGP). The Internet is the main carrier of cyberspace, and ensuring the security of Internet infrastructure is also the key to safeguarding cyberspace security and maintaining cyber sovereignty. A comprehensive and in-depth grasp of the attack and defense methods and principles of Internet infrastructure is an important demand for cyberspace security talents. This course covers 4 parts: Internet system and security, domain name system security, inter-domain routing security, and security thinking and new developments. Each part of the teaching content involves three aspects: principles and systems, safety analysis, and safety protection. Starting from the design of the Internet system, this course reveals the internal relationship between the design and security of the network system and protocols, introduces relevant security analysis methods, and then, alongside the introduction of specific security events, introduces the principle and security of the DNS and BGP protocol as well as the actual system, which are critical for maintaining the normal operation of the Internet. At the same time, this course introduces how to use common network tools such as ping, traceroute, and dig to conduct security analysis and practical operations. By studying this course, you will re-understand the Internet system and network protocols from the perspective of security, and realize that there is a natural contradiction between communication requirements and security requirements; you will develop infrastructure security thinking, be able to analyze the security of Internet infrastructure systems both from a theoretical perspective and by using tools, be able to interpret relevant security events.'
