    en: In order to develop students' ability of data processing and data management in a big data environment, this course will teach the concepts of data, structured data, semi-structured data, unstructured data, big data, and other concepts and corresponding data management theories and methods, and will teach the application of big data in economic and managerial field by case teaching. The management of structured data is mainly done through relational database system, which includes the characteristics of relational database, relational algebra, SQL statements, relational database design, database security and integrity control, etc. The management of semi-structured data and unstructured data is mainly done through the database management system such as key value database and document database, and the relevant contents of the course include the concept of NoSQL, the storage mode of key value database, document database and so on. Students will also learn how to solve the data management problems with a popular relationship database management system, document database management system and key value database management system.
