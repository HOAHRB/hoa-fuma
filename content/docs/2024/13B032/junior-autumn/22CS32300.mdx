    en: Intelligent Software Engineering is a cutting-edge technology in the field of software engineering. The development of internet technology has made the software ecosystem more open, dynamic, complex, and continuously evolving, leading to a rapid increase in the scale and complexity of software systems. This presents significant challenges in terms of improving the efficiency and quality of software development. On the other hand, the rapid advancement of artificial intelligence and the emergence of numerous open-source software and communities have brought new opportunities for the development of software engineering. Internet software development activities, represented by open-source software, have accumulated vast amounts of software big data that are growing rapidly in scale. This data foundation establishes the basis for intelligent software development, enabling software development to evolve from networked and service-oriented to intelligent systems. Intelligent Software Engineering applies artificial intelligence techniques to solve software engineering problems and address the various challenges faced in the field. Through this course, students will gain a comprehensive understanding of the theories and methods of intelligent software engineering. They will also become acquainted with the international research and practical applications of intelligent software engineering and its close integration with engineering practices. The course aims to enhance students' ability to apply these methods to solve practical problems, laying a solid theoretical foundation for future careers in software engineering and related fields. Specific topics covered in the course include the foundational theories of program analysis techniques, deep learning and natural language processing, code representation learning and application, mining of bug repositories, identification of security-related bug reports, data-driven software vulnerability detection and localization, as well as large-scale pre-trained code models.
