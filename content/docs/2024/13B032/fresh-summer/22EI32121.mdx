Especially, LabVIEW in the application of software radio provides a new way for the teaching, experiment, research and development of communication technology. The purpose of this course is to enable students to master the basic method of LabVIEW language programming and gradually form the correct programming ideas, and to enable to use the LabVIEW language programming and achieve the ability to debug the program. From the programming of signal generation, reception and processing, Students can acquire basic concepts of communication system and a strong interest in communication knowledge. The experimental teaching practice of project development will stimulate students’ interest in practical projects, cultivate students’ ability of innovation and programming and the ability of using knowledges to solve practical problems. It lays a solid foundation for the following courses like principles of communication and mobile communication.
