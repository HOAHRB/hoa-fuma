    en: Modern control mainly adopts digital controller, and MCU (MicroController Unit) is the key element of digital controllers, as well as the foundation of embedded systems. Mastering MCU theory, programming and application, is the necessary way for implementing automation control systems. The lecture uses the most popular MCU – STM32 as the target chip, aims to resolve practical system control problems, and explains the involved MCU programming techniques, which contain initializations, interrupt handling, timer, PWM (Pulse Width Modulation) output/input, DMA (Direct Memory Access), I2C, USART etc. Meanwhile, the lecture utilizes these techniques to help students realize a real system’s control, and leads the students to program the control law themselves by the lecture experiments. Before the lectures of automation control theory and automation control practice, this lecture is the efficient way to train the student’s earlier ability, and builds the foundation of allowing students to implement a real automation control system.
