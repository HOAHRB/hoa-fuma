    en: Econometric analysis of big data is the core course of the major of big data management and application, which plays an important role in cultivating students' ability of big data processing and analysis, as well as insight into the commercial connotation of big data. This course introduces the basic theories and methods of econometrics. What’s more, it emphasizes how the classic methods of econometrics can be used in the application analysis of big data. For this purpose, this course mainly focuses on big data processing, the relationship between big data and econometric analysis, and the introduction of special regression analysis models in econometrics. Students should master the application of discrete and restricted dependent variable regression models such as Linear probability model, Logit model, Probit model and Tobit model, Poisson regression model, Negative binomial regression model, zero expansion regression model and other counting models. Students in this course are expected not only to master basic theory, but also to place more emphasis on practical skills. By the end of this course, students should be able to use STATA to conduct basic empirical analyses of interesting business phenomena based on big data.
