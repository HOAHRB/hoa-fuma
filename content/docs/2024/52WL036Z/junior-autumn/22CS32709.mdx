    en: '"Software Construction" is an important foundational course for the Computer Science/Software Engineering major. The course aims to help students build upon their knowledge of advanced programming languages, understand the quality standards and goals of software construction, learn the fundamental processes of software construction, delve into abstract data types and object-oriented programming (OOP), and gain a preliminary grasp of software construction techniques aligned with key quality objectives (such as safety, maintainability, reusability, robustness, correctness, etc.), thereby developing the ability to construct complex software with a focus on quality objectives. The course consists of four parts. The first part covers the foundations of software construction, including multidimensional views of software construction, quality objectives of software construction, software life cycle models, software construction processes, and software configuration management and version control. The second part focuses on abstract data types and object-oriented programming, covering topics such as data types and type checking, function specifications, abstract data types, object-oriented programming, as well as equivalences in ADT and OOP. The third part explores software construction methods and techniques for reusability and maintainability, encompassing metrics for reusability, hierarchical levels and forms of reusable content, design and construction of reusable classes, SOLID principles for maintainable OO design and construction, typical design patterns for reusability and maintainability, as well as regular expressions and grammar-driven programming. The fourth part delves into software construction methods and techniques for robustness, including concepts and metrics for robustness and correctness, exception and error handling, assertions and defensive programming, as well as typical software testing methods and techniques.'
