    en: This course provides an introduction to embedded computer system with an emphasis on its application to robotics. The first part will cover embedded computer architecture, embedded computer instructions and essential peripherals of embedded system. By comparing two computer architectures, namely the new emerging RISCV architecture and the more mature ARM Cortex-M architecture, common features of embedded systems are provided. The second part of this course is about embedded operating system and embedded software development, which will focus on system administration, project management, programming & debugging on embedded Linux. Moreover real-time operating system and real-time Ethernet, which are essential for robotic controllers based on embedded systems, are introduced.
