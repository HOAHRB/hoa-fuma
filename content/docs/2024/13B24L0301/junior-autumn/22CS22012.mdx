    en: The baseline of this course is to answer the question “how to design and implement a basic runnable operating system for a basic computer including a CPU, memory, disk, keyboard and monitor?” In this course, we will describe deeply the six modules of a basic operating system, which are CPU management, memory management, IO management, disk management, file system, user interface and system startup. The principle of the modules, the design of the operating system, and the coding implementation based on open source Linux are included in the lecture of this course. The students, through this course, will get the direct understanding about the whole procedure of an operating system, will achieve the capability of how to design and implement a whole operating system. The students could exploit these understandings and capability in their future career. Meanwhile, many experiments including process design, memory management design and IO subsystem design, are also provided in this course to make the students achieve the capability of designing and implementing a full operating system.
