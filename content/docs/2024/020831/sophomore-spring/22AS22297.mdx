The simulation is helpful to improve people's understanding of various physical processes in the engineering field, save time and experimental costs, improve efficiency, and lay a foundation for engaging in engineering and technical work in the future, and improve product design, development and innovation capabilities. Engineering simulation is a practical technical core course in the field of intelligent manufacturing (2+X mode) in School of Future Technology. It mainly teaches the basic operation process of finite element analysis software (ANSYS) and multi-body system dynamics analysis software (ADAMS), static analysis and dynamic analysis of typical mechanical structures, and motion analysis of typical mechanical systems, so that students can deeply understand and master the basic operation process and use methods of large-scale engineering simulation software, It deepens students' understanding of the basic theory and knowledge of mechanical system, focus on cultivating students' ability to independently analyze and solve problems using computational mechanics analysis software, and have the ability to use large-scale engineering simulation software to solve problems in mechanical system structure analysis, motion analysis, dynamic analysis.
