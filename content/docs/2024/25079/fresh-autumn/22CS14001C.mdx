This version of the course is suitable for the majors which are weakly related to computer techniques. The main contents of this course are as following: (1) Understand basic computational thinking and know how to build a simple computing system based on computational thinking; (2) Understand how program is compiled level by level and finally executed on hardware, and how complex system is built on simple component; (3)Understand problem solving procedure,i.e.problem analysis, algorithm design,and programming, relations among problem, algorithm and computing system, and know how to solve (hard) problem by constructing algorithm and executing algorithm; (4) Understand computational thinking about data management and data mining.
