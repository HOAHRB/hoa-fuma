本页面说明 HOAHRB 教学计划开放平台中的访问统计配置和第三方服务。

## 访问统计

网站仅在部署时同时配置 Umami 脚本地址与网站标识后加载访问统计脚本。
未配置时，前端不会加载 Umami。启用时，数据由所配置的 Umami 服务处理，
具体收集范围和数据存储位置应以该部署所用服务的配置为准。

## 文档浏览偏好

网站使用 Cookie 保存最近浏览的文档路径，方便再次进入文档。

## 第三方服务

页面可能加载 GitHub 头像、外部图片及上游贡献者展示。
访问这些内容时，浏览器会向相应服务发起请求；第三方服务的隐私政策适用于这些请求。

## 联系方式

如有疑问，请通过 [HOAHRB 的 GitHub 仓库](https://github.com/HOAHRB/hoa-fuma/issues) 提出。
