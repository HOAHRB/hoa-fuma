# 课程文档修改

目标文件：课程仓库根目录的 `README.md` 或 `readme.toml`，修改其中一个即可。仅修改 README 时，工作流会反向更新 TOML；修改 TOML 或同时修改两者时，以 TOML 为准。

## 可补充的内容

- 课程名；课程性质（必修/限选/选修、考试/考查、学分学时）
- 教材与参考书
- 授课教师及授课风格
- 授课内容 / 课程建议 / 备考策略

课程信息栏的成绩构成与课程正文的成绩徽章分别读取数据，见 [grades.md](grades.md)。

## 格式要求

- `README.md` 中带板块名称的分割线是 Markdown ↔ toml 双向转换的锚点：**保留原样**，只在对应标题下按现有格式补充内容
- 相对链接中 `..` 表示上一级目录，一般保持原样
- HOAHRB 站点渲染器与 GitHub 预览不完全一致，预览仅供参考

改完回到 SKILL.md 第 6 步公约检查（署名尤其重要），按用户要求交付修改；用户明确要求时再发起 PR。
