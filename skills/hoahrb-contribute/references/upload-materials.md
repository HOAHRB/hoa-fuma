# 资料上传

目标仓库：对应课程仓库（如 `HOAHRB-Courses/<课程仓库>`）。

## 文件放置

按内容放入对应文件夹：

| 文件夹         | 内容                           |
| -------------- | ------------------------------ |
| `assignments/` | 作业                           |
| `exams/`       | 试卷及答案                     |
| `notes/`       | 个人笔记                       |
| `slides/`      | 来自教师的资料（须经老师同意） |

## 流程

1. Fork 课程仓库并 clone 到本地（大仓库 clone 慢时，可建议用户改用 GitHub 网页上传或 Codespaces）
2. 将文件复制到对应文件夹，文件名清晰可辨（建议含年份/学期，如 `2025春期末试卷.pdf`）
3. 检查文件本身符合公约：无盗版、无未授权课件、无考核相关答案
4. 按用户要求交付修改；用户明确要求时再发起 PR（回到 SKILL.md 第 7 步）

上传多个文件到**不同**文件夹属于多文件夹上传，只能通过 git 本地操作或 Codespaces 完成，GitHub 网页单次上传只支持单一目标文件夹。
